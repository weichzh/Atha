# Atha

Atha 是一个本地优先、以消息形式保存阅读反应的个人阅读系统。

当前只推进 Windows，并遵循“后端先于前端”。移动平台、Windows 前端和正式产品后端都尚未开始；现有 `p0/` 仅为 FFI 与 SQLite 技术验证。
