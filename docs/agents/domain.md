# Domain Docs

This repository uses a single-context domain documentation layout.

## Before exploring

Read these when they exist:

- `CONTEXT.md` at the repository root;
- relevant ADRs under `docs/decisions/`.

If a file does not exist, proceed silently. Create domain documentation only when terminology or decisions are actually resolved.

## Vocabulary

Use terminology defined in `CONTEXT.md`. Surface conflicts with an existing ADR explicitly instead of silently overriding it.
