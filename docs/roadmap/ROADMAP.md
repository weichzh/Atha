# 路线图

路线图只定义顺序，不授权生产代码修改。每个里程碑仍需独立规格、计划、交叉审阅和用户批准。

## M0：项目工作流初始化

目标：建立 `ACTIVE` 优先、规格先于代码、计划交叉审阅的项目记忆系统。

退出条件：

- 旧提案已迁移且不再与当前决策竞争；
- 架构、代码地图、数据库基线和路线图可独立读取；
- 文档守卫与长度检查通过；
- 工作流初始化形成独立提交。

## M1：Windows 后端工程初始化

目标：建立正式根 Cargo workspace 和最小后端 crate，但不实现产品功能。

必须先决定：

- crate 边界和公开接口；
- 固定 SQLite 方案与版本；
- 迁移入口；
- 错误模型；
- 格式化、静态检查、测试和本地基准命令；
- P0 实验如何被引用而非复制。

退出条件：空后端可构建、检查命令可重复、没有业务占位代码。

## M2：首个后端纵向切片

目标：完成“创建书籍上下文 → 保存引用笔记和 SourceAnchor → 同事务写 Outbox → FTS 检索当前修订”。

退出条件：

- 信任边界输入验证；
- 事务故障注入；
- 版本化迁移；
- 当前修订搜索语义；
- 内容不进入日志；
- 本地集成测试与最小性能证据。

## M3：Windows 阅读导入后端

目标：安全导入 TXT，并建立可恢复位置；EPUB 解析器需在规格阶段选型。

退出条件：异常文件安全失败、资源上限、位置恢复、索引后台化和诊断脱敏均有验证。

## M4：Windows 前端壳

目标：在后端接口稳定后建立 Windows 窄窗口 UI，先接书架与 M2 纵向用例。

前端不得直接访问 SQLite。阅读、笔记和回顾状态按独立规格逐步加入。

## 暂缓范围

- iOS、HarmonyOS 和其他移动平台；
- PDF、OCR、MOBI、AZW 与词典；
- 云同步、账户和 AI 书友；
- 商业化、遥测上传和生产发布。
