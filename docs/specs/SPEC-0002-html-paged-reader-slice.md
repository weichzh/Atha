# SPEC-0002：本地 XHTML 分页阅读切片

## 状态

accepted

## 问题

当前项目没有可验证的 HTML 阅读路径，无法证明复杂本地 CSS、SVG 与公式能够在可读字号和分页边界内正确呈现。

## 目标

从三个受控的本地 XHTML 样本加载内容，在固定阅读页中呈现并分页；以实际 Windows 阅读承载页面作为产品验收对象，并用浏览器自动化复核同一阅读页代码与明暗主题。

## 非目标

- 不把 EPUB 解包或导入做成产品能力；本地样本提取仅服务验收；
- 不修改或修复书源；
- 不实现滚动阅读、持久化、笔记或消息；
- 不将验收截图作为产品数据格式。

## 用户可见行为

- Windows 首个阅读引擎使用 WebView2，由 `wry 0.56` 与 `tao 0.36` 提供最小承载；
- 打开数理逻辑 1.2、宏观经济学 5.2 或范畴论 5.6 本地样本后，用户看到固定 1264 × 1680 的分页阅读页；
- 正文暂用 32px 与 1.6 行距；这些是本样本的实验参数，不是产品默认阅读设置；
- 行内公式保留原书相对大小，随用户正文字号等比变化；
- 行间公式使用独立的显示倍率，在内容列中居中，过宽时完整缩小到页内；
- 页面底部不得出现被裁切的文字行、公式或图形；
- 阅读页跟随系统 `prefers-color-scheme`；夜间模式使用深色页面、工具栏与正文，并保持公式和插图可辨；
- 书内脚本不执行，外部资源不加载。

## 内部行为

- ATHA 阅读页的 HTML、CSS 与 JavaScript 是唯一实现来源；实际 Windows 承载与 Agent Browser 都加载同一份阅读页代码，后者只自动执行验收；
- 输入为 `fixtures/local/` 下的三个本地样本；该目录必须保持本机忽略；
- 可复用提取脚本从用户指定 EPUB、XHTML 入口和可选 section id 生成最小样本，只复制目标 XHTML、直属样式和目标内容引用的资源，不修改源 EPUB；ZIP 项逐项拒绝绝对路径、盘符、UNC、反斜杠、父目录、符号链接与输出根越界，禁止 `extractall`；
- 书籍内容是不可信输入：它不得拥有宿主命令、文件系统、网络或进程权限；
- 内容资源只按当前书籍根目录内的相对路径解析。路径越界、符号链接越界、外部 URL、书内脚本、事件处理器和主动跳转均拒绝，并向读者明确报错；
- 普通图片只允许书根内资源；本切片拒绝含 `@import` 或 `url()` 的书源 CSS，也拒绝 SVG 脚本、事件属性和外部引用；`data:`、`blob:` 及其他协议不允许；
- 本切片不提供“确认加载外部资源”界面，外部资源一律拒绝；该限制不替代产品长期的确认加载方向；
- 样式顺序为书源 CSS、ATHA 阅读样式、用户样式；本切片没有用户样式配置界面；
- 样本中的公式选择器固定为 `.math-inline` 与 `.math-display`，不得根据 SVG 或 PNG 文件名猜测；含公式的逻辑与宏观经济学样本分别断言至少一个公式并检查全部实际公式，不硬编码某一本书的公式总数；范畴论样本断言零公式、至少一个代码块和恰好两张可加载的普通 PNG，不把图示伪装成公式；
- 正式环回服务只读并只绑定 `127.0.0.1`；仓库阅读页与用户指定书根分别规范化，请求路径通过所属根校验后才读取；
- 两类公式保留各自源尺寸，不归一为同高。行内公式以书源 16px 正文字号为基准随当前字号等比缩放；行间公式在该倍率上再乘本样本实测的 `1.5`，并覆盖书源内联边距以在内容列中居中，过宽时继续等比缩小；普通 SVG 不进入公式适配；
- 分页采用固定逻辑页上的浏览器原生 CSS 多栏，不逐行搬运字符串或节点；内容区上下各保留 2px 字形缓冲，原子内容避免栏内断开；
- 每次布局后必须测量文字 `Range`、公式与图形的实际矩形。一行文字、公式或图形要么完整位于当前页内容区，要么完整移入下一页；发现裁切或单一内容高于整页时明确报错。

## 验收标准

- [x] 1.2 样本不含 1.3 标题或内容，所有直接本地图片可加载；
- [x] 脚本与外部网络资源均未执行或加载；
- [x] 字号从 24px、32px 到 40px 时，行内公式使用同一比例变化且不被统一为同高；
- [x] 字号为 24px、32px、40px 时，未触发页宽上限的行间公式倍率分别为 `字号 / 16 × 1.5`，宽高比与源尺寸一致，中心相对内容列偏差不超过 2px，过宽时不裁切；
- [x] 固定页内容区内不存在任何被裁切的文字行；
- [x] 实际 Windows 承载页面通过上述行为验收；Agent Browser 对同一 ATHA 阅读页代码的截图、控制台与请求检查可复核结果，但不代替实际承载页面验收；
- [x] 技术预检已在 `ADR-0003` 记录承载库、自定义资源协议、书籍隔离、公式选择器、分页模型和安全探针；
- [x] 实际 Windows 承载页面记录冷启动、热启动、首个稳定页面、首次翻页和字号重排的耗时；每项至少记录 10 次、保留原始样本并报告中位数与 P95；
- [x] 每次性能基准在忽略的 `artifacts/local/benchmarks/` 中写入结构化本地记录；记录不得含书名、正文、公式内容、搜索词、外部 URL 或用户笔记；
- [x] 本地运行日志与性能基准分开保存；运行日志同样不得含书名、正文、公式内容、搜索词、外部 URL 或用户笔记。
- [x] 可复用脚本从两本指定 EPUB 分别生成宏观经济学 5.2 与范畴论 5.6 最小样本，重复执行结果一致，源 EPUB 不变；
- [x] 宏观经济学样本包含“5.2 引入人力资本”且不含 5.1、5.3；范畴论样本包含“5.6 余积”且不含 5.5、5.7；
- [x] 实际 Windows host 对三个样本的 24/32/40px 分页与资源自检均通过，含公式样本的全部实际公式自检通过；
- [x] 可复用 Agent Browser 验收命令为三个样本生成明暗模式截图；正文与页面背景对比度不低于 4.5，控制台无阅读器错误；暗色下全部且仅公式类图片启用反色，普通插图在明暗模式下均为 `filter: none`；
- [x] 提取、环回服务与视觉验收均为 `scripts/` 内正式代码，验收不依赖一次性 `.tmp` 脚本。

## 边界情况

- 书源把多个章节错误包在一起时，样本切片可以裁出验收范围，但产品运行时必须明确报告而不是修复；
- 未标记为公式的 SVG 视为普通资源；
- 单行或单图自身高于整页时，记录明确错误或例外，不静默丢失内容。

## 风险

- WebView2 和验收浏览器的版本差异仍可能影响结果，最终结论以实际 Windows 阅读承载页面为准；
- 公式 SVG 的内部留白会影响视觉大小；`1.5` 是当前样本的实验显示倍率，不是跨书籍默认值；
- PNG 公式可能自带白底；夜间模式只反色公式类图片，普通插图保持原色；
- 分页边界依赖 WebView2 的实际布局矩形，升级运行时后必须回归；
- 首切片先建立基线，不预先承诺跨机器的绝对性能阈值。

## 性能记录

性能记录只保存在本机。每条记录包含运行标识、渲染器版本、样本稳定标识、页面参数、冷/热状态、阶段定义和各阶段耗时；保留原始十次样本以便重新计算，不上传，也不包含书籍或读者内容。运行日志另行轮转保存，只记录错误类型、阶段和非内容性的环境信息。
