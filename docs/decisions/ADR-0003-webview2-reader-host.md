# ADR-0003：WebView2 阅读承载与分页边界

## 状态

accepted

## 背景

`SPEC-0002` 要求在 Windows WebView2 中读取不可信的本地 XHTML，同时限制文件和网络能力，并让实际承载与 Agent Browser 复用同一份阅读页代码。实现前预检需要确定最小承载组合、资源边界、分页模型和公式规则。

## 决策

1. Windows 阅读渲染固定使用 WebView2。产品入口采用 Tauri 2 与 Svelte 5；直接使用 `wry 0.56` 与 `tao 0.36` 的 `atha-reader-host` 在迁移期保留为性能与安全回归基线。
2. Tauri 产品入口由随包 asset scheme 提供阅读器资源，旧 Wry/Tao 基线继续使用 `atha`；两者的书籍资源都只通过 `atha-book` 自定义协议暴露一次会话指定的规范化书根。
3. 书籍资源解析先解码并规范化路径，再拒绝绝对路径、父目录、符号链接越界、未知 MIME 和书根外文件。书籍请求只返回给阅读器来源所需的精确 CORS 头。
4. 阅读器 CSP 默认拒绝所有能力，只开放自身脚本、样式和受控书籍资源；所有导航、新窗口、下载和外部请求均拒绝。书籍没有宿主命令接口；唯一 IPC 是来源与字段均受校验的单向非内容性能事件。
5. XHTML 在独立 `DOMParser` 文档中解析并校验后才导入。脚本、事件属性、表单、框架、主动跳转及非书内资源均报错。M2 直接拒绝含 `@import` 或 `url()` 的书源 CSS；SVG 先解析并拒绝脚本、事件属性和外部引用。
6. 分页使用浏览器原生 CSS 多栏布局，不按字符串或节点搬运内容。页面填充 WebView 视口，内部设备像素尺寸等于视口 CSS 像素乘 `devicePixelRatio`，页内字号和固定边距使用绝对设备像素，显示层以 `1 / devicePixelRatio` 抵消系统 DPI；宿主窗口与壳层控件使用 Windows 逻辑像素。窗口变化经 Navigation 队列以 Locator 恢复位置。内容区上下各保留 2px 字形缓冲，原子块使用 `break-inside: avoid`。每次布局后以文本 `Range` 和原子元素矩形检查断页边界，发现裁切即报错。
7. 样本公式选择器固定为 `.math-inline` 和 `.math-display`。行内公式以书源 16px 为基准随正文字号等比缩放；行间公式在该倍率上乘实验系数 `1.5`，覆盖书源内联边距后在内容列中居中，并在超宽时继续等比缩小到内容宽度。
8. 性能阶段使用单调时钟：冷启动从进程入口到首个稳定页，热打开从同一 WebView 内再次装载已访问资源到稳定页，翻页到下一绘制帧，字号重排到连续两个稳定绘制帧。正式检查每项保留至少 10 个原始样本，并在本地计算中位数与 P95。

## 预检证据

- Windows WebView2 Runtime：`150.0.4078.105`；Rust 与 Cargo：`1.97.1`。
- 1.2 样本识别到 148 个行内公式、6 个行间公式和 154 个图片资源。
- 24px、32px、40px 三档均通过边界检查；最终预检为 4 页、0 个裁切项。
- CSP 外联探针产生 1 次预期违规，独立本机 TCP 监听器收到 0 个连接。
- 实际窗口已人工检查首屏、翻页和 32px 到 40px 重排；预检耗时仅用于证明可测，不作为跨机器阈值。
- 实施截图回归发现书源内联 `margin: 0` 覆盖阅读器居中规则，且行间公式复用行内倍率时视觉墨迹偏小；几何探针确认独立 `1.5` 显示倍率可保持宽高比、4 页和 0 裁切。

## 影响

- 后端只负责书根和遥测边界；分页、公式适配与 DOM 检查留在唯一阅读页实现中，避免 Rust 与 JavaScript 双份算法。
- 页面设备像素与 Windows 壳层逻辑像素相互独立；系统 DPI 可以放大窗口和控件，但不会改变页内字号和固定边距，窗口可用范围变化才触发重新分页。
- Agent Browser 验收可用临时本地验证服务提供同一组阅读页文件，但这不是产品运行路径。
- 含复杂 CSS 资源引用的书籍会在 M2 明确失败；以后确有样本需求时再引入完整 CSS 解析。

## 备选方案

- 直接使用 `webview2-com`：否决；需要大量不安全 COM 代码，与 workspace 的 `unsafe_code = "forbid"` 冲突。
- WebView2 虚拟主机映射：否决；文件夹映射不能为每个请求执行同等精确的书根与 MIME 校验。
- Tauri：M2 基础切片曾因没有产品壳需求而暂缓；当微信读书式界面、桌面构建与成熟 UI 生态成为真实需求后采用，并以同一 WebView2 内核和既有性能门槛验收。
- 自建 HTTP 服务：否决；增加监听端口和攻击面，且自定义协议已满足资源边界。
