# 开书动效

## Status

implemented

## Problem

封面退得太快，露出的全屏正文与手中书本大小不搭。用户希望像翻开一本书：看一眼封面，翻开后再靠近正文，不显示「正在打开」。

## Scope

用户批准并在 Android ARM64 真机上验收了开书动效。本候选在已合入主线的[阅读器前置 PR #4](https://github.com/weichzh/Atha/pull/4)（`326e7e7`）上移植试读版的封面与取景，不混入移动书架改版、阅读控件改版、正文仿真翻页或图标。桌面原生跨文档打开、外部文件入口、原文锚点和书籍资源边界沿用现行契约。

## Architecture Impact

present

- 应用壳持有打开请求、封面与回焦点；阅读器在恢复内容和定位后报告首屏就绪。书架开书不等附加笔记读取；阅读记忆跳转仍以保存的原文锚点为准。
- 封面与真实正文共用书脊原点。选择在布局外缩放，以保持字号比例、换行与位置；分页和图像稳定性测量折回原布局坐标。
- Android 返回键交给应用返回栈；取消后迟到的 IPC 或章节结果不进入界面。保留原生外部文档入口，不增加依赖。

## Acceptance Criteria

- [x] 先揭开与封面同尺寸的真实内页，再将纸和字一起放大；不换行、不跳位，普通打开约 1–2 秒。
- [x] 慢开书保留封面或来路，不显示等待文案或转圈；支持返回与 Escape，减少动态时跳过空间过渡；失败可回书架。
- [x] 返回恢复滚动和焦点；取消不覆盖原阅读位置，阅读后可从原位置重开。
- [x] 用户在原 Android ARM64 试读版确认最终动效自然。
- [ ] 拆分候选经独立 PR 审查并合入 GitHub `main`。

## Files And Steps

1. `App.svelte`、书架和打开适配器协调打开、取消和返回；`MainActivity.kt` 接上 Android 返回桥。
2. `BookOpeningCover.svelte` 和 `ReaderView.svelte` 对齐封面和正文；`reader/web` 保留分页和阅读位置。
3. 在前置合入后对照主线复核差异，独立提交 PR；记录候选与手机试读版的证据边界。

## Checks

运行仓库文档与工作流检查、Svelte 检查、Vite 构建、阅读状态单测和 Chromium 浏览器门。定向检查 390×844 的纸面几何、失败与取消、降动效、返回后的分页与滚动位置，以及模拟 Android IPC 迟到回包。隔离 Xvfb 的 Linux Tauri/WebKitGTK 跑原生文件打开与回退门。

## Iteration Control

- Mode: `iterative`
- 停止条件：用户确认自然，冻结体验；拆分时纠正影响原验收的回归。

## Result

| 轮次           | 问题与修复                                                                                      | 验证                                                                         |
| -------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 1 · 封面到正文 | 等恢复章节与 Locator 再交接；仍因封面太短和等待文案打断阅读。                                   | Chromium 定向检查与 Android 真机试读。                                       |
| 2 · 沿书脊翻盖 | 保留封面、移除等待界面和循环动画；取消后忽略迟到结果。真机反馈是封面与正文尺寸仍不搭。          | Chromium 约 1.6 秒，检查慢开书、取消与迟到回包；Android 真机试读。           |
| 3 · 同尺寸内页 | 封面用约 480 ms 就位，停至少 420 ms；翻盖前 350 ms 露出同尺寸内页，接着 410 ms 纸和字等比放大。 | Chromium 约 1.75 秒，行数不变、交接偏差小于 1 CSS px；Android 真机用户接受。 |

拆分候选在 390×844 Chromium 测得约 1.75 秒，文字几何偏差小于 1 CSS px。DPR 1 和 3 在取景时触发重排，均保留第 2/4 页和同一 Locator；即时退出再进滚动位置从 390 回到 388 px。浏览器门与 Linux 原生热开书门通过；Android ARM64 未签名 APK 构建通过。

## Review

拆分验证发现旧主题未定义过渡返回按钮的安全区变量：增加 Android 安全区读取与 CSS 默认值，实测等待中的按钮可点，取消保留 Locator 和焦点。封面使用平滑减速的贝塞尔曲线，无弹跳、无忽略项。主线基线、开书源码及测试分别与实测候选一致，沿用同一份验证证据。

## Evidence And Residual Risks

真机验收对应原工作区构建的试读包；拆分候选使用独立本机证据，未覆盖安装、未在 Windows WebView2 运行。完整回执与截图留在 Git 忽略目录。若发现行为回归，回退动效 PR，保留前置阅读器。
