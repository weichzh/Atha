# 多级章节目录

## Status

implemented

## Problem

导入器拍平章节目录时丢失原书层级，阅读器把卷、章、节显示在同一层，长目录难以查找。

## Scope

从已批准交付的阅读交互 V2 中独立拆出多级目录。保留 EPUB nav / NCX、FB2、Markdown 与 Kindle 已有目录的层级；在现有目录面板显示和折叠。纯文本与旧缓存保持可读，未提供层级的目录不按章节标题猜测。脚注、正文布局、书架和开书动效另交付。

## Architecture Impact

present

- schema 1 TOC 条目新增可选整数 `level`（1–6），省略表示第一层。章节与 href 仍按原顺序、唯一性及书根约束验证，不写入 Locator。
- 导入器只发布已能跳转的目录项。新渲染器读取平面与分层清单，不重建旧缓存，不更改源文件身份。
- 目录树是前端显示模型，保留平面下标来查找和跳转。独立的折叠按钮不改变位置；点击标题走既有跳转。

## Acceptance Criteria

- [x] 源目录父子关系可见，新旧缓存均能在更新后的阅读器打开；非法字段、超限层级和越界目标仍拒绝。
- [x] 折叠不跳页，当前章节路径在重新打开目录时可见；章节跳转仍走原有目标。
- [x] 通过受影响格式、manifest 与浏览器交互检查。
- [ ] 独立审查后合入。

## Files And Steps

更新四个导入器与 `reader/web/session.mjs` 的 TOC 契约，再接入阅读目录的显示树；用可公开的嵌套样本贯通导入与跳转。

## Checks

Rust 格式导入与清单校验测试、JS 目录树和 manifest 边界测试、Svelte/Vite 构建、窄屏 Chromium 目录折叠与跳转。

## Iteration Control

- Mode: `iterative`
- 停止条件：目录顺序、目标、结构及现有入口通过复验；不改变其它工作区布局。

## Result

公开合成测试覆盖 EPUB nav 与 NCX、带原文锚点的 FB2、Markdown 标题和 Kindle 重复目标。会话同时接受平面与分层清单，拒绝非法层级、未知字段和越界目标。390×844 Chromium 通过键盘折叠与展开、折叠不换章、点击目标跳章，以及重开目录后高亮当前节。类型检查和构建通过。

## Review

本地原实现直接按语法深度缩进，可能使无链接或被去重的父节点的子项错误归入相邻章节。按保留下来的父链写层级，不补造跳转目标；旧目录没有层级时不从标题猜测。代码与安全独立审查走本候选 PR。

## Evidence And Residual Risks

旧缓存沿用平面目录，不迁移或重写存量书籍。回退到只认识平面目录的旧主机时，新分层缓存需从保留的原始书源重新生成；阅读位置与消息数据无需变更。未在物理手机或 Windows 上重新验收本切片。
