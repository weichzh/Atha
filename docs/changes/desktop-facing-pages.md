# 桌面对页与笔记分栏试用

## Status

implemented

## Problem

现有卷页以整块阅读区域为一张纸。桌面横屏留有空间，但正文与动效都没有左右对页的结构。展开笔记时，需要兼顾正文可读性与笔记列表、对话的连续性。

## Scope

用户批准本地试用：宽横屏默认对页，卷页从中缝翻动单张纸；结合窗口宽度、比例及正文实际剩余宽度安排正文、笔记列表、对话。初版观感未获接受，随后批准采用本地 Readest 源码，撤去纸框与浮卡，移植真正的卷曲，并暂停全量检查。保留连续滚动、窄窗口、移动端和单幅 CBZ 的行为。

## Architecture Impact

present

- Design purpose: 同一正文按一列或两列分组导航，Locator 仍引用同一份正文。
- Drivers / quality scenarios: 宽横屏对页，展开侧栏保留阅读位置；超长章末页与减少动态仍可读。
- Modules / Interfaces / Seams / Adapters: 工作区共用尺寸规则；内核按实际 frame 选择步长。翻页图层仅读取当前安全 DOM。
- Candidate and tradeoffs: 不复制正文数据，不改 Locator、IPC 或书籍信任边界；对页卷曲将 Readest 的折线、半径和背面映射接入现有 WebGL，单页保留既有路径。
- Evidence / ADR / review trigger: 本地试读；复核中缝、双面内容和分栏往返后再决定正式提审。

## Acceptance Criteria

- 宽横屏同时显示相邻两页、有可见中缝。选「卷页」时，从中缝翻一张，正反面对应相邻页，支持正反向和取消。
- 翻页不唤起上下工具栏。工具栏已展开时，按钮、键盘和手势均使用默认快速翻页；收起后恢复原动效偏好。
- 宽窗口容纳正文、列表和对话；宽度不足时正文回到单页或与对话分阶段显示。关闭笔记返回原阅读位置。
- 保持短章、奇数末页、长章、窄屏、连续滚动和减少动态的导航行为。

## Files And Steps

1. 共用窗口分档，按正文实际宽度决定正文排版。
2. 以一份正文连续排版，实现对页步进与中缝两面翻书。
3. 检查实际渲染和阅读、笔记往返。

## Checks

- 本轮先看真实 EPUB 的静止双页、卷曲中途和贴边笔记；只做对页关键交互、静态检查及构建。暂不跑全量检查。

## Iteration Control

- Mode: `iterative`
- Maximum repair iterations: `3`
- Unchanged-delta limit: `1`
- Human stop: 需要更改存储、信任边界、操作真机或对外发布时停止。
- Per-iteration receipt: 写入 Result，截图和输出留在本地忽略目录。

## Approval

用户批准实现桌面端试用。发布、提审和合入不在本轮。

## Rollback

回退本分支变更即可恢复单页与旧分栏，既有书籍偏好及 Locator 格式不变。

## Result

- 正文可用宽度至少 1160 CSS px、窗口高至少 560 CSS px 且宽高比至少 1.3 时，桌面分页默认对页。横屏阅读区不够宽时回到单页。连续滚动、CBZ、Android 保持既有布局。
- 宽至少 1360 CSS px 且宽高比至少 1.4 时，笔记保留正文、列表、对话三列；较紧凑的横屏分阶段显示正文与列表、列表与对话。窄屏或竖屏仍用底部面板。笔记列表换位时只移动视觉图层，两次排版之间仍用原 Locator。
- 静止双页共用底色。移除纸框、投影和粗中缝；桌面笔记贴边，用分隔线区分列表和对话，移动端底部面板不变。
- 在「排版与主题设置 → 本书覆盖 → 阅读方式 → 卷页」试用。外缘抬起、折线向中缝收拢、背面露出目标跨页；取消时不提交导航。无法忠实光栅化的内容或 WebGL 不可用时，用原样 DOM 覆盖过渡。
- 上下工具栏展开时，进度按钮、键盘和触拖都走默认快速翻页。展开工具栏立即结束正在播放的卷页；收起后恢复原动效偏好。Chromium 定向检查覆盖了这两种状态和切换。
- Linux WebKitGTK 在隔离 X11 窗口实际导入 Readest 的《爱丽丝梦游仙境》EPUB，检查了静止双页、卷曲中途和鼠标选区打开笔记草稿。Chromium 仅运行 `page-turn.browser.mjs --spread-only`，验证正反向、取消、上下文丢失、调整窗口和减少动态。Svelte 静态检查与本地构建通过。

## Review

- 核对了《爱丽丝梦游仙境》的实拍截图，卷曲能看见目标叶上的正向文字。双层图案仅使用已有安全正文的临时渲染结果，不增加书籍资源读取路径。

## Evidence And Residual Risks

- 真实 EPUB 截图：`artifacts/local/page-turn/readest-desktop/`。本轮没有重跑全量或性能检查；X11 与 Chromium 均用软件渲染，未测 Windows WebView2。初版的 `linux.json` 不作为这一版的全量结果。
