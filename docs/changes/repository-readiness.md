# 正式开发基线收尾

## Status

accepted

## Problem

主线还没有轻量本地提审流程；候选文档门存在漏报，Linux 完整原生验收及其下游、Windows 书架入口引用旧界面。已交付工作的 Git 引用、托管工作树、文档状态和本机产物还未收尾，阅读链路和资料耐久性仍有未完成验收。

## Scope

- 从公开 `main` 整理净候选，只承接已验证的本地提审改动；修复审查发现的四类文档门漏报。不引入 GitHub Actions、推送时重跑或新调度器。
- 修复 Linux 全量、AppImage、公式及 Windows 书架的在用验证入口；维持参数、隔离、安全检查和证据含义。已有 AppImage 不因后续构建失败被删除。
- 收口已完成的流程文档，清点可回收 Git 引用、旧任务工作树与本机产物，区分正式基线、归档、可重建缓存与仍有价值的证据；保留私人资产和未发布历史。发布、合并、远端写入、真实设备和删除按各自权限执行。
- 利用公开或原创样本核验现有读取和持久化链路。Issue #1 与 #2 只记录实际覆盖，仍待目标环境或样本的验收保持开放。

## Architecture Impact

none

不替换产品模块、数据语义或 WebView；修复仓库验证入口和证据归属，不新增产品依赖。

## Acceptance Criteria

- 候选历史不带废弃 CI 实验。文档门对工具链差异、坏 `ACTIVE` 路由、两种模式的 `reader/` 差异和已提交的空白错误有正反向回归；合法纯文档仍轻量通过。
- Linux 全量使用当前书架 DOM，在隔离资料目录走完原有有效验收；AppImage 不覆盖旧包，直接验证新包中的 launcher 与文件关联；公式保持默认样本阈值并区分合成证据。Windows 脚本使用现行界面契约，证据区分静态、夹具与实际 WebView2。
- 按当前事实更正文档和验收缺口。候选对在途、归档和可回收对象有逐项可核列表；不把没有未提交改动当成清理完成。

## Files And Steps

以净差异引入上一轮本地提审流程。三个独立工作面分头修复工作流门、Linux 验收族、Windows 书架门；在同一候选整合并核对引用和实测，最后按保留边界交接收尾动作。

## Checks

临时 Git 夹具和仓库文档门；真实 Linux WebKitGTK、实际包与公式的可用隔离样本；Windows PowerShell 静态或夹具检查；保留现有本地测试证据、核对相应文件差异和实际提交。

## Iteration Control

- Mode: `iterative`
- Maximum repair iterations: `4`
- Unchanged-delta limit: `1`
- Human stop: 真实设备、私人样本、外部写入或不可逆清理需要相应授权；证据不得跨环境冒用。

## Result

先前审计已复现文档门漏报及全量 Linux 在启动后寻找旧选择器的问题。收尾候选从公开 `main` 和已实测的净差异起步。

- 提审门：两种模式共用路径分类与 `ACTIVE` 检查；已提交候选按实际 PR 的三点差异检查路径和空白错误。临时 Git 历史的 10 项回归通过，包含四类已复现的漏报、合法纯文档和跨边界重命名。当前整合树 `bash scripts/check-workflow.sh --base origin/main` 通过。
- Windows 书架：旧进度分组、全选、浏览器弹窗由当前状态筛选、逐册多选和应用确认弹窗替代。PowerShell 语法及路径隔离正反例、Chromium 生产构建四视口夹具和排序失效注入均通过。Windows 原生选择器与 WebView2 待目标机使用[原创 EPUB 复验](../agents/references.md#webview2)。
- 资料耐久性：新增原创 EPUB 的完整资料库往返回归。给真实导入的章节点保存笔记、Locator 和 PNG 快照，备份到隔离制品并恢复到另一份资料库；重新打开存储后核对 Locator 所指章节、原文、快照字节和 SQLite 完整性。`cargo test --locked --offline -p atha-backend --test local_data` 通过 15 项；未启用私有词典用例的样本路径。本项是后端回归，不代替重启后的界面回跳或跨端验收。
- 已合入的 GitHub Flow 草案从当前文档移除，PR #3 和 Git 保存历史。路线图将公式性能门的当前证据指向代码地图；代码地图区分资料库备份已实现及仍未提供的加密、checkpoint 和同步。
- 回收候选已按 GitHub 远端头与主线可达性核对：20 个远端短期分支、24 个本地已合入分支、1 个失效跟踪引用。5 个完成的原生 worktree 里现存的验收产物已另存到主工作区忽略目录；旧基线保留一个归档头。未执行清理。

## Review

按实际候选检查原有验收入口的适用场景、失败语义、保护范围和证据。

## Evidence And Residual Risks

本机证据放在 `artifacts/local/`。原生端、包以及公开／私人样本的验证结论分别记录。

- Linux 原生首次打开「阅读记忆」时，界面为「全部记忆片段」发出空查询，后端按现行搜索契约拒绝，页面进入重试态；浏览器 demo 对同一请求返回最近记忆。非空搜索、历史快照和原文回跳是不同场景，不能用它们的通过覆盖首次打开。
