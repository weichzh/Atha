# 页内脚注预览

## Status

implemented

## Problem

点击正文脚注会立即跳到注释处，读者需重新找回原段落。跨章注释也应能在原地查看。

## Scope

从已批准交付的阅读交互 V2 中独立拆出脚注预览。支持同章和跨章的书内注释、关闭回读、明确跳转。保留普通链接、外链拦截、原文 Locator 和现有书籍资源边界；不改目录、页动效或书架。

## Architecture Impact

present

- 会话只预读 manifest 已声明的章节，复用正文的验证和资源清单，不激活章节或改变阅读位置。
- 仅将注释的纯文本投影到原生对话框；书籍标记、图片和链接不进入该界面的 DOM。仍可明确跳到原文。
- 退出、切章和后来的脚注请求使旧请求失效；原生返回或 Escape 先关预览。

## Acceptance Criteria

- [x] 同章、跨章注释可读；展开、关闭和失败都保持原 Locator。
- [x] 只有点击「跳转原文」才进入可用脚注；普通链接行为不变。
- [x] 空锚点或仅含图片的脚注仍可明确跳转；缺失目标保持原处。
- [x] 返回后不显示迟到结果；未声明的章节与外部目标不会被预读。
- [ ] 通过独立审查并合入。

## Files And Steps

接通会话的只读章节准备与阅读器脚注识别，使用原生对话框显示纯文本；用隔离原创 fixture 检查同章、跨章、迟到和拒绝路径。

## Checks

会话与导航单测、Svelte/Vite、仓库文档门、窄屏 Chromium 交互及视觉检查。

## Iteration Control

- Mode: `iterative`
- 停止条件：原地预览、关闭、明确跳转和安全边界通过。

## Result

桌面 1280px 的脚注贴近锚点；390px 窄屏显示底部注释卡。Chromium 验证了同章与跨章注释、Escape 回焦、触摸在外关闭、返回关闭与取消迟到请求；预览、取消与失败均未改写 Locator，明确跳转才换章。未声明目标未发起请求，章内注释不带原书 DOM。Svelte、Vite、会话、导航单测与仓库工作流检查通过。

## Review

原实现异步预读没有按请求失效，补上会话与请求状态检查；Chrome 等价用例覆盖未声明目标及迟到回包。显式跳转按 manifest 完整 URL 匹配，避免 WebView 自定义协议的空 origin 导致回退。

首轮代码审查指出空锚点和仅含图片的脚注不一定有可预览文字，原候选因此丢失跳转入口。现在按「目标存在」保留跳转按钮，只有缺失目标给出提示且不换章；Chromium 补测两类脚注。

## Evidence And Residual Risks

浏览器验证了界面与交互；单测验证自定义协议跳转。此候选未运行真实 Android、Windows 或 Linux WebView 的脚注界面检查，未安装到用户设备。
