# 恢复 V2 书架、应用设置与阅读控件

## Status

implemented

## Problem

#22 保留了模式切换，却没有带入原版经典五按钮底栏、独立进度浮层和完整极简菜单；书架和设置的呈现也与 V2 原版不同。以清理前最后保留下来的未提交 V2 源码和变更记录为准；不同轮次的截图只辅助核对。

## Scope

恢复 V2 书架工具栏、排序与选择模式、贴底主导航、应用设置分组首页与子页、两种阅读控件布局和入口。以当前单页滑动修复 `27ccfd4` 为基底，保留现有藏书筛选、书架回焦点、分页、连续滚动、原文定位、安全区、主题与原生返回契约。极简不强制把本书切到分页；沿用已验收的开书动画、笔记和卷页。关联 [Issue #1](https://github.com/weichzh/Atha/issues/1)。

恢复的是布局与操作入口。极简底栏箭头沿用主线的切章，上一页／下一页在进度浮层内；新会话仍默认按书名排序。

## Architecture Impact

none

## Acceptance Criteria

- 经典底栏依次是目录、笔记、进度、日夜、样式。进度浮层按需打开，可翻相邻页和拖进度，关闭后焦点回到入口。
- 极简顶栏左侧返回，标题可开目录，右侧三点菜单提供目录、书签、笔记、进度、日夜、排版及直接回经典。底栏保留切章和书内进度。
- 书架恢复搜索、视图、选择同排和紧随其后的单行排序；窄屏恢复贴底导航；多选恢复顶部全选、册数和完成，已选筛选条件与批量确认仍可达。应用设置恢复分组卡片、按需展开搜索与聚焦子页，阅读和书架偏好用直接可选的按钮，不丢设置状态。
- 控件切换不改变正文几何或阅读模式；Escape 与宿主 Back 先关闭子浮层；翻页、主题、导航、书签手势、选区及减少动态的既有行为继续通过。

## Files And Steps

按 V2 源码逐项对照现行书架、设置和阅读控件，复用现有偏好、Popover 和阅读引擎。同步浏览器和 Linux 验收入口的按钮路径，在同一候选中验证恢复布局与既有滑动修复。

## Checks

Svelte、生产构建、Chromium 阅读控件/阅读器/翻页回归，以及与影响范围相称的 Linux 原生、候选文档门。

## Iteration Control

- Mode: `iterative`
- Maximum repair iterations: `3`
- Unchanged-delta limit: `1`
- Human stop: 候选出现待决定的交互取舍或需要操作实体设备时停止扩大范围。

## Approval

用户批准恢复最终 V2 界面并合并，范围包括书架、设置和阅读控件。

## Review

独立只读审查对照本候选、主线和恢复的 V2 源码。找到的界面行为退化与错误的默认值收到第 3 轮；没有改动单页滑动的实现。

## Evidence And Residual Risks

最终 Linux Tauri 候选在 GNOME Wayland／WebKitGTK 跑通书架整理、阅读控件、设置、阅读记忆与原文回跳。独立内核低采样夹具执行每场景 0 次预热／2 次采样、共 22 次可信鼠标手势；首轮一次公式拖动未翻页，单独复跑通过。该采样验证行为，不作为正式 P95 门成绩。

主线既有的「进度」排序仍使用添加时间排序；本轮保留入口，不修改排序算法。Android 真机与 Windows WebView2 未在本轮操作。
