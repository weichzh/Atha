# 书架多选和批量操作

## Status

implemented

## Problem

每本书独立的封面菜单遮挡封面，整理多册时需要反复打开菜单。书架需要一个随选择数量变化的操作区。

## Scope

从已获准分批交付的阅读交互 V2 中提取书架多选。保留现有搜索、筛选、排序、布局、开书过渡与焦点恢复；继续用现有书籍适配器和确认边界。不在本批改书架布局、继续阅读区域、设置、系统栏或阅读控件。

## Architecture Impact

none

仅改变书架上的操作入口及选择状态，仍按现有接口逐册写入本地书库。

## Acceptance Criteria

- [x] 长按、右键、键盘或可见的「选择」能进入同一模式；短按仍打开原书，滚动不误触。
- [x] 浮动底栏随选择数量变化；保留原单册操作，多册可收藏、移出和删除，涉及移出或删除必须先确认。
- [x] 搜索与筛选继续可用；范围变化不会把不可见书籍带入批量操作。取消选择或关闭确认保留书架位置。
- [x] 批量写入遇到故障时，准确报告完成数量，停止后续写入。待恢复的删除沿用原有恢复流程。

## Files And Steps

在 `LibraryView.svelte` 接入选择和原生返回，沿用 `ConfirmDialog` 与书架适配器。补充隔离书库的浏览器用例；[Issue #1](https://github.com/weichzh/Atha/issues/1) 跟踪真实链路。

## Checks

Svelte、Vite、仓库工作流检查；桌面和 390px Chromium 复验三种入口、单/多册操作、确认取消、过滤与开书返回。

## Iteration Control

- Mode: `single-pass`
- 停止条件：新入口不误开书，现有书架操作与数据边界通过回归。

## Result

Chromium 桌面和 390px 窄屏覆盖右键、Shift+F10、长按、滑动取消和开书返回。单册换封面、恢复默认封面及多册收藏、移出、删除使用隔离演示书库；注入第二册移出失败后，底栏保留未处理的两册，第三册未被移出。窄屏多选底栏临时替代导航，退出即恢复；选中标识与收藏标识分开。Svelte 检查、Vite 构建、书架单测和工作流检查通过。

## Review

发布前差异检查确认只改书架选择与批量操作。独立审查在 PR 中进行。

## Evidence And Residual Risks

本批证据是 Chromium 触摸事件及书架单测，原生删除恢复路径沿用已验证的逐册逻辑。原 V2 的模拟器结果不作为此候选的证据；Android 与 Windows 未运行。
